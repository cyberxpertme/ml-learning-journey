---

## 1. Computer Fundamentals

A computer is an electronic system that receives input, processes data according to instructions, and produces output.

### Hardware

Physical components of a computer:

- CPU
- RAM
- SSD/HDD
- GPU
- Keyboard
- Monitor

### CPU

CPU (Central Processing Unit) executes instructions and performs computational operations.

### RAM

RAM (Random Access Memory) is temporary working memory used by running programs and the data they need.

### Storage

Storage provides long-term data storage.

---

## 2. Hardware vs Software

### Hardware

Physical components of a computer.

### Software

Programs and instructions that allow the computer to perform tasks.

### Examples

**System Software:**

- Windows
- Linux
- Kali Linux
- Ubuntu

**Application / Development Software:**

- VS Code
- Web browsers
- Other user applications

---

## 3. Operating System

An Operating System manages computer resources and provides an interface between applications and the underlying hardware.

Examples:

- Windows
- Linux
- Ubuntu
- Kali Linux

Basic relationship:

```text
Application
     ↓
Operating System
     ↓
Hardware
```
