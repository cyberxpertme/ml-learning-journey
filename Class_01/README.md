## 📚 What I Learned Today

### 1️⃣ What is an Engineer?
An engineer is someone who **solves real problems** using knowledge, tools, and systematic thinking. An engineer does not just follow instructions — they **understand why** something works.

### 2️⃣ What is an AI Engineer?
An AI Engineer builds intelligent systems using:
- Machine Learning
- Deep Learning  
- Large Language Models (LLMs)
- Data Engineering

They are different from traditional programmers — they **teach machines** to solve problems instead of writing every rule manually.

### 3️⃣ Traditional Programming vs Machine Learning

| Traditional Programming | Machine Learning |
|------------------------|-----------------|
| Human writes every rule | Machine learns rules from data |
| Fixed logic | Adapts from examples |
| Input + Rules → Output | Input + Output → Rules (Model) |
| Good for simple tasks | Good for complex patterns |

### 4️⃣ AI → ML → Deep Learning → LLM
Each layer is **more specific** and **more powerful** than the previous one.

### 5️⃣ Key Concepts

| Concept | Definition |
|---------|-----------|
| **Data** | Raw facts and numbers |
| **Dataset** | A collection of data |
| **Feature** | Input variable (e.g., age, size) |
| **Label** | Output variable (e.g., price, category) |
| **Training** | Teaching the model with data |
| **Model** | The learned pattern |
| **Prediction** | Model's answer for new data |

### 6️⃣ Research Skill
> Reading documentation, arXiv papers, and Stack Overflow — not just tutorials.

### 7️⃣ Learning Strategy
- **Spaced Repetition** — Review after 1 day, 3 days, 7 days
- **Active Recall** — Test yourself without looking at notes
- **Feynman Technique** — Explain it simply to understand deeply

### 8️⃣ Documentation
> Everything I learn must be documented.  
> If it's not written, it didn't happen.
